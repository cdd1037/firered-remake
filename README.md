# FireRed remake

Private source checkpoint repository for the Godot/.NET FireRed research project.

Small, verified development checkpoints are synchronized here. Full milestone recovery archives are backed up separately to Google Drive.

This repository excludes ROMs, game image/audio resources, generated caches, saved games, large verification artifacts, and the historical asset-bearing Git database. Resource acquisition and reconstruction instructions accompany the source snapshots.

Initial audited source snapshot upload is in progress; this initialization commit alone is not the complete project.
