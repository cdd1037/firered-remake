# 当前场外与物品接线

本页只描述当前边界；真实业务支持范围见[当前状态](first-clear-remaining-scope.md)，数据目录见[内容组合](current-content-composition.md)。

## 物品

共享道具和机器目录提供定义、袋分类、兼容性与实际服务引用。普通操作必须保留数量、容量、消耗时机、不可用场景、HM安全及当前物种准入，不能用旧阶段人数/profile代替。

糖果、药品和进化石按当前目录和真实进化边执行。所有者注册表、旧阶段背包投影链和纯来源指纹已经退休；不要照旧报告重新给这些接口加入证明对象。

## 遇敌与场外

当前仍有区域型遭遇工厂及特殊起源状态。只移除来源字段不等于已形成通用EncounterCatalog。草地、水域、钓竿、碎岩、狩猎、游走与固定遭遇的实际选择/RNG和场景限制要分别保留。

后续将原版一致性测试与运行表合法性分开，降低增加地图时的重复接线；具体问题和顺序见[质量审核](project-quality-review.md)。

## 验证

规则检查在Domain/Battle，公共命令与存读在Application，资源引用/生成在Content与ResourceImport。使用[标准测试入口](../tests/README.md)，不要求恢复旧的独立阶段工程或证据JSON。受控夹具通过不等于自然完整路线。
