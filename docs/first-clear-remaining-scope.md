- 共享命名：开局、宝可梦昵称与PC盒名使用同一源模板／键盘呈现和直接键盘输入，保留各自事务／字符上限／取消语义；PC命名及实际捕获昵称已有有界原生验证，IME／Help组合仍未独立验证。见[共享命名](shared-naming-presentation.md)。
