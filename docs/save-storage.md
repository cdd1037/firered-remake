# 存档序列化与体积

玩家存档仍是可读 JSON，schema 3、rules/content 版本、generation 和完整性校验不变。
本轮不压缩、不引入二进制容器，也不自动迁移或改写原存档。

## 本轮唯一省略项

只有 `SaveCodec.Encode` 的类型化载荷写入省略三项纯计算结果：

- `SixStats.Values`：由六个具名数值字段即时组成。
- `PokemonInstance.IsShiny`：由已存的 OT ID 与 personality 计算。
- `CampaignActor.Visible`：由已存的 Active 与 Invisible 计算。

规则按确切类型和属性绑定，不对其他对象的同名字段生效，也不使用全局
`IgnoreReadOnlyProperties`。稳定 ID 的只读 Value 是权威身份，继续保存。
普通 JSON 序列化、`CanonicalJson.Hash(state)`、资源输出与诊断结构不变。
显式转换器传入的 `JsonNode`／`JsonElement` 原始载荷不删字段。

已有 schema 3 JSON 即使含这些冗余字段仍可读取。校验先针对原始载荷执行，
之后才反序列化和语义准入；不能靠修改被忽略的旧字段绕过 checksum。
新载荷 checksum 与完整状态诊断 hash 可能不同，两者用途不可混用。
联盟保存请求与主档读回继续比较完整状态的 canonical hash。

保存前语义校验、编码后回读、staged 字节一致性、有效 primary 才进入 backup、
Continue 候选文件指纹和损坏主档回退流程均未改动。schema 1/2 仍拒绝，缺失
真实孵蛋总数等问题不通过估算或此项体积优化修复。

## 为什么不删其他较大字段

当前队伍、箱子、培育屋中的个体、背包、RNG、allocator 与进度统计是权威状态。
训练家结算、捕获／进化来源、NPC 交换和名人堂记录仍被业务准入或游戏显示读取，
不能仅因名字含 History／Receipt 就删掉。今后如收敛这些结构，需要先移交其
业务职责、定义显式版本转换，并证明所有仍被引用的记录都保留。

训练家记录目前还承担连续 battle ID、再战赢家约束、进化来源、联盟开始／结束
所指的历史下标与名人堂 battle ID。false flag 也不等于可省略字段：可再生隐藏物品
明确检查部分 flag 是否存在。空箱子槽位保留坐标，不能不带索引直接删除 null。

## 测量和验证

2026-10-20，以 SDK 10.0.401／实际运行时 10.0.12，对同一对象分别执行原来的
完整类型序列化和新的三项省略。两份载荷都通过 checksum 与解码，恢复后的完整
canonical 状态 hash 和 generation 相同。

| 实测输入 | 原 JSON 字节 | 新 JSON 字节 | 节省 |
| --- | ---: | ---: | ---: |
| 当前 schema 3 中文新游戏 | 10,371 | 10,371 | 0 |
| 同一新游戏执行 71 条公开命令，到 Oak 引导入所结束 | 18,499 | 18,349 | 150（0.81%） |
| 1 个个体的箱子序列化向量 | 3,690 | 3,628 | 62（1.68%） |
| 60 个个体的箱子序列化向量 | 74,117 | 70,157 | 3,960（5.34%） |
| 420 个个体的箱子序列化向量 | 504,571 | 476,815 | 27,756（5.50%） |

前两项是实际新游戏／公开命令状态，均通过完整 `ValidatePlayerSave`。后三项用当前
物种工厂生成个体并填入固定箱子布局，只验证容量序列化，不是完整合法 campaign、
玩家取得历史或后期游玩档。无个体、无地图 actor 的开局没有这三项重复数据，
因此没有体积收益；不对所有存档承诺固定节省比例。

测量源程序与结果保存在本地 `evidence/refactor-20261020/save-size-probe/` 和
`save-size-measurement.json`。编码耗时／累计分配也记录在结果中，但测量期间有
其他测试并发，不据此宣称速度、磁盘性能、峰值内存或游戏帧率改善。

集成串行解决方案构建为 0 警告／0 错误。Application 定向回归 152/152，
其中本文件对应的 `SavePayloadSizeTests` 为 11/11，包含旧字段兼容、旧字段篡改
checksum 拒绝、原始 JSON 保真、稳定 ID、主档／备份、stage 替换、候选指纹、
实际 `PokemonLeagueDurableSave` 读回、中文新游戏 Continue 与三种容量向量。
这些检查不替代原生窗口、完整自然流程或导出验收，本轮未导出。

当前仅存的 generation-57604 历史样本是 schema 1／campaign-v3，不能作为当前
Continue 或自然后期游玩基线。
