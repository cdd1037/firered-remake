# 导入与资源架构整治（2026-10-16）

## 本轮目标

在上一轮抽取共享函数之后，继续消除历史开发阶段架构。保留真正的游戏功能、
地图与图像语义，取消前驱包、累计物种数量、源码证明、旧入口兼容层等无运行价值
的依赖。本轮没有新增玩法、替换字体或改变声音合成算法。

## 结构结果

- 地图由一个 raw→最终格式编译器生成。唯一 world 索引选择395张普通地图和19个
  真实布局变体，统一生成瓦片表、地图图集和NPC图集。42个旧地图入口已退役。
- C#组合根只加载一次 world，并显式传入功能读取器；去掉58个地域连接薄包装。
  无全局隐式缓存，不通过先后加载地区来补地图身份。
- 遭遇、地形机关、NPC交换、钓竿、赠物等按真实业务编译。删除旧地图准备目录、
  无消费者的合同以及与阶段进度相关的数量门槛。
- 音频只读一个1117项cue目录；由固定源码和既有pack/叫声库生成。删除27个地区
  音频入口及运行时增量注册链。合成器和样本数据未改变。
- 物种、招式学习和机器兼容性使用共享canonical数据；删除重复地区投影和前驱
  名单。训练家保留真实队伍、战斗绑定和自然招式解析。
- 专用图片转换直接使用源读取器与纯图像函数，不再动态加载某个地区CLI来借工具。
  修正旧grid菜单的“JSON文件名当目录”和邮件编写器的过时输出位置。
- 编排统一为 `rebuild-resources.py` 的明确资源目标。缺输入即失败，不跳过后报告
  成功，不保留旧services/postgame包装链。具体范围见[再生成说明](resource-reconstruction-guide.md)。

## 规模

以本轮之前已提交的 `ff116d2` 为基准，统计作者维护的Python源码（scripts、tools及
测试中的Python；排除raw、缓存、日志）：

- Python文件：470 → 392；物理行：67,385 → 47,952，净减19,433行，约28.8%。
- 导入命令文件：338 → 240，净减98个。
- 配方文件：212 → 164；1,431,119 → 657,457字节，约减少54.1%。

这些数字包含新增功能编译器与测试。没有靠压行、移出统计目录或把代码转成巨型
JSON制造减量。此前第一轮整合的74,169行起点属于另一个基准，不混为本轮净减。

  1088帧及其anchor/动画、开场玩家图像与旧最终资源一致；包含20张开场边框归属迁移。
- 地图原始二进制、metatile属性、事件顺序、脚本入口和真实变体由独立检查器验证。
- 音频旧460项cue字段保持一致；17个离线场景的34份PCM／控制结果一致。音频606项
  测试与13项导入测试通过，按需执行，不加入默认全量测试。
- 共享机器目录保持57种TM/HM定义、386种物种和22,388项兼容性；真实服务、训练家、
  邮件、图像以及源数据变异检查通过。
- 最终串行solution构建：零警告、零错误。

  定向复测全部通过。其余族测试另有直接Python回归，不把不同层级测试数相加。

  使用Dummy音频，并以外部终止结束；不声称实际听感、窗口视觉或优雅退出验收。

## 边界

运行时不依赖raw或pret；再生成需要对应固定原始输入。world和上述目标的冷生成
与等价验证，不等同于已经证明所有专用UI/故事/音频样本能够一条命令从零重建。

真实的特殊转换配置仍保留；不为减少文件数将所有职责塞入一个大脚本。后续新增
内容必须接入真实功能或共享转换，不恢复地区累计包和历史数量门禁。

本轮没有完整自然通关、逐个招式视觉验收、实际扬声器验收或备份恢复重放。Drive
保持暂停；源码同步只使用既定治理分支。临时检查结果保留在工程外或忽略目录，
不作为运行资源及工程交付内容。
