## 已收敛的职责

- 宝可梦：区域展示与进化展示采用两个统一命令；canonical 物种与增量选择复用同一字段／性别／成长率／学习表解析器。差量配方保留真实资源选择，不复制累计物种定义。
- 训练家：统一源声明、队伍、自然招式、区域战斗绑定及头像转换。故事／物品转换器直接复用解析器，保留特殊剧情行为；修复实验室共享表发布到错误目录的问题。
- 地图：共用原图解码、拓扑、脚本索引和可达脚本遍历；清屏VRAM、动态图层等差异明确配置。运行目录直接按区域组合，删除历史阶段目录包装入口。
- 展示：合并物种图片入口及重复的调色板／帧处理；大型地区转换共用固定源读取，删除自生成的输入清单配方。
- 物品：共用效果、图标和普通拾取解析；机器视图直接使用现有共享 admissions，删除重复的机器数值与物种名单。SS Anne／Route11 普通物品使用统一命令。
- 配方：删除无消费者的历史命令摘要、依赖快照和自写 inventory。真正的输入选择、特殊资源绑定和输出结构保留；没有通过把重复 Python 全量转写成 JSON 来制造精简数字。

新的常用命令见 [scripts 说明](../scripts/README.md)。旧入口已删除，不保留兼容转发森林。

## 验证方式

重构前从同一份保留 raw 实际生成临时基线；重构后对 JSON 字段、完整解码 RGBA 和其他二进制内容比较。纯 PNG 编码差异不应导致 `--check` 假失败，透明像素的 RGB 也参与比较。

- 宝可梦展示：494个产物（含456张PNG）；另验证canonical全386种及实际增量输出。
- 训练家：共享604个定义、Vs Seeker351支队伍、区域绑定和38个头像产物。
- 地图：43张地图、308个像素缓冲、15组源脚本闭包和12组显式区域目录。
- 展示：739个实际再生产物，以及180组真实源调色板／帧核心对照。
- 六组物品转换：79个产物（14 JSON、65 PNG）保持逐字节一致。
- 四组机器视图及Rock Tunnel跨调用：22个产物保持逐字节一致。

默认入口也分别验证了散图与图集裁剪后的合法表示；不以文件已打包为由跳过像素和业务字段检查。早期五区训练家必要入口的过时读写路径已修正，实际隔离重建30个战斗绑定通过。

这些集合有职责交叠，不相加为“独立资源总数”。新增检查接入 Game.ResourceImport.Tests；组合回归还检查生成资源加载。历史失败日志保留，不用更新黄金文件掩盖真实差异。

## 保留的边界

本轮验证真实保留 raw 输入与已有依赖资源，未声称从完整固定 Git checkout 一次冷重建整个游戏。部分依赖 Git 的特殊资源入口，以及缺原 cue 输入的音频历史增量流程仍有边界。早期训练家有真实独立战斗绑定职责，保留该转换器而非强行删除。明确存在独特剧情、遇敌、音频或展示职责的转换器没有为了行数强行合并。

没有对备份包执行恢复重放；没有新增原生窗口或真实扬声器验收。Drive 同步仍暂停。
