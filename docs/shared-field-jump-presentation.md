# Shared field jump presentation

Live field movement and Quest Log playback use the same pure source movement sample. Recorded source actions, start times, durations and accepted destination coordinates remain authoritative; no save field or gameplay command was added.

The source `event_object_movement.c` regular far/high jump moves one pixel per callback for 32 callbacks. Special/high jumps move on alternating callbacks for 32 callbacks. In-place high and reversing in-place normal jumps take 16 callbacks. The shared sample uses the original high/normal Y tables, keeping sprite Y offset separate from the tile/world/camera anchor. Its elapsed value counts completed callbacks: zero is the pre-movement pose, one includes the initializer's immediate first update, and the final callback clears Y2. This removes the prior live ledge/Surf table duplication and their inconsistent elapsed offsets. All four directional far jumps share the same path, rather than recognizing only downward scripted ledges.

The timeline already retained each SourceAction; it now exposes the shared Y offset alongside position fraction. Recap special jumps also use the discrete alternate-pixel schedule instead of linear interpolation. Surf rider offset is applied to the rider, leaving the blob/world anchor unchanged. Existing recorded durations and gameplay outcomes are unchanged.

The original checkpoint closed displacement/arc presentation only; ordinary shadow/dust effects are added below. Direction-reversal animation selection and the broader special-pose catalog remain separate. New supported transitions now carry producer-owned cause/phase evidence and share the live/recap transition controller; see [ordinary transitions](plain-field-transition-presentation.md). Historical destination-only records still do not identify warp versus connected-edge/forced transitions, so no fade is inferred from those map changes.

## Ordinary shadow and landing effects (2026-10-19)

Ordinary one-tile `jump_*` actions now use the same source 16-callback normal arc
as their recorded playback. The existing far, in-place, reverse and special arc
paths retain their source values. Ordinary jump wrappers create a ground shadow
before their first callback and clear it on the final callback, including the
zero-height frames near landing. Far jumps change logical terrain at callback16;
initial or later forbidden terrain destroys the shadow without recreating it in
the second half. `CampaignFieldJumpEffects` holds this shared sampling and source
terrain selector; it does not advance world state, steps, RNG or save fields.

Fixed source `event_object_movement.c` InitJumpRegular/UpdateJumpAnim and
GetGroundEffectFlags_JumpLanding, plus `field_effect_helpers.c` FldEff_Shadow,
UpdateShadowFieldEffect and FldEff_Dust supply the lifecycle. Shadow size comes
from each graphics declaration through the existing shared overworld catalog.
The same importer emits all four source shadow images using OBJ palette zero;
full transparent image bounds and source anchors are retained. Existing ground
impact dust pixels are reused. Source sprite callback-before-animation ordering
retains the third dust tile for its END-observation frame: visible ages0..24,
removed at age25 (8+8+9 frames).

Live transient cues survive subsequent walking while their dust tail finishes;
map reconstruction and full-screen field-owner replacement clear them. Recap
cues derive from existing recorded action/position/timing values, including the
same tail and map boundary, without a new recording schema. Both rendering paths
use the same effect sampler and palette transformation. Effects never extend an
input or script wait. Ordinary ground dust is admitted only after the source's
grass/water selector; separate tall-grass and splash effects are not substituted
with dust. Surf special jumps retain their existing owner.

Source oracle outputs stay local and ignored. Generate them explicitly with
`tests/Reference/generate_field_jump_vectors.py` and
`tests/Reference/generate_field_jump_effect_vectors.py`, using the maintained
fixed reference and each test's reported output command. Source C checks cover
