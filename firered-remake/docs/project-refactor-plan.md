# 当前重构方向

当前可执行的治理清单与证据统一见[项目质量审核](project-quality-review.md)，实施顺序见[当前路线](implementation-roadmap.md)。本页不再追加旧里程碑报告。

## 已有且应保留

- 五程序集边界、共享普通四位置战斗内核。
- 单一当前组合、显式规则目录、不可变状态/revision/RNG。
- 原始输入/运行资源分离，共享物种、招式、道具、训练家及图集。
- 8个维护测试项目、独立数值向量、真实存档完整性/backup保护。

## 尚需收敛

- 日常操作中的取证负担、不断积累的无必要历史与重复校验。
- 把原版一致性验收与运行时合法性分开；统一普通菜单/遇敌/服务的真实数据来源。
- 导入工具不再借地区CLI作库或重演旧阶段名单。
- 模态流程和资源所有权清晰，不把多份partial文件等同于模块解耦。
- 正常启动、独立交付及当前文档闭环。

不新增catalog-owner证明注册中心、通用插件平台、历史版本恢复器或全工程hash锁。可接受明确的内部API/存档结构调整，但必须保留真正业务状态和必要检查点；不把破坏兼容作为默认目标。
