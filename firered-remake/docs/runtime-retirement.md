# 退休运行时的边界

正常游戏只使用当前组合，见[当前启动和存档](current-game-composition.md)。旧地区profile、历史会话工厂、逐阶段升级路由不再是维护入口。

probe/harness是明确标记的原创工程夹具，不是旧版本FireRed运行时。它们通过不代表当前游戏内容或自然路线通过。

旧阶段的测试工程与来源证明日志不能重新作为启动前提。维护测试使用[当前八项目](../tests/README.md)；被删除测试的范围说明保留在[退休清单](test-retirement-20261015.json)。

当前仍有少量首战等专用规则、区域型数据绑定和内容门槛，不能把“退休旧runtime profile”误读成全部历史结构已经消失。改进以[质量审核](project-quality-review.md)为准。
