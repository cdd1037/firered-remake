# Four-slot Cute Charm checkpoint

The same `SourceRecipeContext.ContactCuteCharm` recipe runs from the historical
singles bridge and the actual four-position kernel. Its source is
`battle_util.c` at `037335f4c725d7c9aecdac87066f2002b4bd7e14`, specifically
`ABILITY_CUTE_CHARM` and `CANCELLER_IN_LOVE`.

The checkpoint includes slot-owned infatuation, source action-canceller ordering,
all-source departure cleanup, and position-owned damage receipts. It deliberately
keeps `% 3 == 0`; the generic move-secondary probability correction is unrelated.
No recipient is recovered from side or species. Canonical contact uses retained
physical/special damage even when the fresh callback damage is zero. Future Sight
sets the damage sentinel and physical receipt, survives Ready, and is cleared by
the next ActionFinished. Legacy non-source profiles retain their existing gates.

Prerequisite: a9f7c0f plus the declared source-hit-items dependency. The frozen
30-case old singles baseline was captured independently from that exact composed
source tree (local b8bc00c), before the contact edits. It hashes complete results,
including state, events and RNG trace. The baseline is not regenerated by run.sh.

The probe extracts and compiles the original C branches without editing them.
The bounded environment stubs supply source genders already verified by actual
source Pokemon construction, RNG, HP and receipt registers. This is a callback
and canceller differential, not a ROM execution claim. 156 cases check position,
no-effect/HP/contact/receipt gates, same gender, genderless attacker, Oblivious,
existing love, exact RNG, and the love action decision. Reflection only reaches
the internal recipe boundary for these command-level vectors.

Nineteen actual four-action turns use source-legal Clefairy/Jigglypuff donors and
retained legal moves. They include infatuation across Ready, two separate reward
pauses, cancelled fainted actors, a same-species replacement with a fresh occupant
serial, Future Sight receipt lifetime, and transient-frame JSON round trips.
The four-slot moves used here do not stand in for the Route8 Twins' real moves;
those belong to the separate shared Twins move recipe checkpoint. Its Frame
`CancellerCancelMultiTurn` override supplies Rollout cancellation to the same
love recipe. The old-single baseline includes a real Rollout/love cancellation.

Scope remains source-only. This does not claim Application/campaign admission,
full354 execution, or player battle saving. Rough Skin, Poison Point, Flame Body,
Effect Spore and Color Change remain explicitly gated in the four-position
kernel. Existing singles implementations are retained; Static is unchanged.

Integration notes: preserve the separately added `FrameRecipeContext` partial
class, its turn-move cancellation override and its per-hit move-end hooks. The
receipt clear belongs at FinishAction, never a per-hit CompleteScriptTarget.
An older hit-item test that rejected any valid four-position receipt must now be
narrowed to still-unported held items; receipt-only frames are intentionally open.
