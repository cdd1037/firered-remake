# Four-position source entry proof

See `docs/source-four-slot-entry-abilities.md` for source provenance, lifecycle and admission bounds.

```sh
bash tests/Game.FourEntryAbilities.Tests/run.sh AUTHENTICATED_CONTENT_ROOT PINNED_SOURCE_ROOT NEW_EVIDENCE_DIRECTORY
```

Uses the official content-root SDK, BCL-only local restore and per-build shared lock. Each successful fixture checks canonical identity after execution. Real turns and replacements are counted separately from source-query vectors. Failed development logs remain in local evidence; only the final result is acceptance.

The `7d1983e` combination also verifies real Trace-copied Truant/Static, sleep before copied Truant, and atomic rejection of a retained Focus Band hit flag. The shared canceller regression initializes its native Intimidate holder through the real entry boundary.

The optional fourth argument `--type-changes` runs the bounded shared Color Change / Conversion / Conversion 2 migration checks using the same authenticated holder/entry/turn helpers. It covers both spread targets, actual right-slot move history, Trace plus type overlays, ordinary switch lifetime, complete turns, malformed overlays, closed caller admission and exact singles adapter state/event/RNG parity.
