# Four-slot forced Struggle

Run `bash tests/Game.FourStruggle.Tests/run.sh PRODUCT_ROOT PINNED_REFERENCE_ROOT NEW_EVIDENCE_DIRECTORY` with the existing official toolchain. It uses the same shared build lock and the product's local-only NuGet configuration. No new assets, downloads or config files are required.

The source probe checks commit `037335f4c725d7c9aecdac87066f2002b4bd7e14`, compiles the verbatim `CheckMoveLimitations`, `AreAllMovesUnusable` and `GetMoveTarget` functions with bounded environment stubs, and the verbatim recoil command scalar. It freezes 80 PP/Disable cases, 192 selection/action target cases 256 damage-dealt recoil values, and 16 combined both-sides-exhausted vectors for the explicitly selected controller-ready order (enemy 1, enemy 3, player 0, player 2). Source hashes identify every reference input. This is extracted original C execution, not ROM execution.

`legacy-baseline-bda2d6a.json` contains 72 whole-result SHA256 hashes captured before changing the existing singleton scalar recipe, from fixed parent `bda2d6a7bf3722e1dd910e711e25bdd1d5c8f095`. They include complete state, ordered typed events and RNG trace for real forced Struggle turns with normal/Rock Head actors, Ghost/Rock/Normal targets, Burn and one-HP recoil KOs. The normal runner compares those immutable results; it never regenerates the baseline.

The focused runner also covers real four-slot turns with one actor, one side or both sides exhausted; positive-PP Disable; rejection of unsupported-but-selectable moves as a fallback; zero PP without negative values; target rerolls, Follow Me and a complete turn against the sole far-side opponent with Pressure; misses and typeless physical damage without Normal STAB; actual recoil and target KO, exact-once reward to the surviving partner, remaining queued action and end-turn replacement boundary; prior chosen-position priority; an earned queued action after PP restoration; forced Rollout/recharge; true original Twins rosters with one or both enemies exhausted; and atomic stale revision/occupant/continuation, invalid selected slot/target and RNG exhaustion. Every four-slot continuation is replayed through serialized state and compared exactly.

The old `Game.Route8Twins.Tests` exhausted-PP assertion now expects the actual Struggle choice; its other 252 original C/AI assembly vectors remain unchanged. Application/native admission and the integration with the separate held-berry patch are verified by their respective owners.
