# Shared selected volatile-target checks

Run from the candidate repository:

```sh
bash tests/Game.FourVolatileTargets.Tests/run.sh PRODUCT_ROOT PINNED_REFERENCE NEW_OUTPUT_DIRECTORY
```

PRODUCT_ROOT supplies existing content and pinned toolchains read-only. Compilation
uses `/tmp/firered-remake-build.lock`; runtime evidence uses the isolated output.
The project references only Domain and Content. It does not build Godot or launch
a GUI. Actual tested runtime must have major version 10.

The source probe verifies the exact reference commit and executes verbatim source
confusion, Wrap, prevent-escape and Wrap-residual case bodies in a small authored C
harness. Its 16 duration/RNG vectors and six residual vectors are frozen in
source-vectors.json. It checks source script command ordering and departure links.
It does not execute reference-repository scripts.

Program.cs tests actual four-slot source targeting, Follow Me, ally Pressure,
Own Tempo, Soundproof, existing confusion, Safeguard, Protect, flinch, no PP, misses,
six trapping definitions, independent same-species targets, repeated Wrap,
expiry, switch lock rejection, source departure, both directions of Baton Pass,
real Roar entry, direct source faint, and Wrap KO with deferred replacement and
serialized cursor replay. Controlled combat fixtures use authenticated species,
abilities, stats and move definitions, with intentionally selected move sets for
isolating command behavior; they do not claim authentic natural learnsets.

LegacyParity.cs captures complete serialized states, events and RNG traces for 36
affected-family actions (12 moves, three seeds). The baseline hash was captured
from unchanged source before extraction. The candidate must match that immutable
hash and also compare 36 canonical-singles adapter actions with the public
singles coordinator. The latter uses an explicit empty CalledField to select the
existing source-extension adapter validation path. No broad historical suite is
run for this change.

Authored inputs retained with this test: Program.cs, LegacyParity.cs,
Game.FourVolatileTargets.Tests.csproj, packages.lock.json, run.sh, source_probe.py,
source-vectors.json, legacy-baseline.json and this README. The evidence directory
retains final output, source hashes and the earlier fixture-validation failure.
The first adapter fixture lacked a source extension and hit the existing
wild_battle_catalog_profile validator; it was fixed before the final run.
