# Unchanged singles Spikes contract

This harness saves 33 SHA-256 hashes of complete state/event/RNG outputs. It covers original single-position voluntary, Baton and forced switching, hazard KO/replacement, full source-wild turns, source Pressure/capped layers, and Baton Passed Rooted/Substitute against ordinary, Flying and Levitate entrants.

Run through `tests/Game.SharedSpikes.Tests/run.sh` to compile this exact harness against both fixed old production `e14578e` and the candidate source, then compare byte-for-byte. Expected outputs are produced from the independent fixed baseline, never rewritten from candidate behavior.
