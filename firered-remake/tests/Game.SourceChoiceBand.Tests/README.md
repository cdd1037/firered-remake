# Source Choice Band differential

Run `bash tests/Game.SourceChoiceBand.Tests/run.sh REAL_PRODUCT_ROOT PINNED_PRET_ROOT NEW_EVIDENCE_DIRECTORY` with the official SDK configured by the product environment. No external NuGet packages or GUI.

The 1,540-vector extractor authenticates original item/source files and compiles the exact move-end case and u16 Attack branch. The 512-vector extractor compiles unchanged CalculateBaseDamage with newly reconstructed, explicitly bounded register stubs from `Game.DamageAbilityGaps.Tests`. Separate complete-turn and direct-action fixtures require authentic species moves and preserve the distinction between fixture mechanics and campaign admission. Focus Band is a separate unimplemented capability.

The command writes fresh source hashes, controlled C source/executables, vectors, build/run logs and nonempty result counts. Historical Forest and source end-turn stdout comparisons against the fixed implementation baseline belong to the separate historical evidence report.
