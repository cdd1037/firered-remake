# 应用层

`Game.Application` 只引用 `Game.Domain`，负责命令会话、剧情与交互流程、事务和存档操作。目录用于定位职责，类型名、命名空间及程序集边界保持不变；游戏规则不依赖文件夹名称。跨模块契约见[架构](../../docs/architecture.md)。

## 目录

| 目录 | 职责 |
| --- | --- |
| `Sessions/` | 游戏启动选择、当前会话、目录绑定、命令 revision 和游玩计时 |
| `Persistence/` | 存档编码、canonical JSON、玩家存读操作和结果 |
| `Battle/` | 普通单/双打、训练家、野生战斗、捕获和回执投影 |
| `Battle/Animation/` | 从业务事件生成动画调用、结果时序与表现参数 |
| `Field/` | 移动、场外技能、遇敌、拾取与地图交互；`Transitions/` 保存过渡时序与纯 C# 表现模型 |
| `Pokemon/` | 成长、进化、队伍、持物、赠蛋和交换；`Storage/` 负责盒子操作 |
| `Inventory/` | 库存、道具、药品、机器和邮件事务 |
| `Services/` | 治疗、商店、招式服务、游戏厅等共享服务 |
| `UI/` | 菜单准入与设置、图鉴、地图、档案和收集界面所需的应用操作 |
| `QuestLog/` | 回顾事件捕获、游标、时间线与地图状态 |
| `Tutorials/` | 老人捕获教学和 Teachy TV 的独立流程 |
| `World/` | 跨地区剧情、对白、旅行和再战；`Regions/` 按场景组织地区流程 |
| `Diagnostics/` | 显式工程与参考世界会话 |

`CampaignSession` 的 partial 文件随功能归档，仍组成同一类型。地区目录只组织现有流程；新增内容应先复用共享机制，不能通过目录名添加地区白名单或规则豁免。

## 编译与验证

SDK 默认递归发现 C# 源码。表现测试链接其中的纯 C# 文件，移动时须同步更新显式路径和通配符，保留原有编译输入与 `Link` 名称。招式教学导入工具的绑定代码输出位于 `Services/CampaignMoveTutorBindings.cs`。

本次仅整理目录与路径，未修改 C# 源码内容。移动前后检查、完整命令及构建阻塞见[验证记录](../../docs/validation.md#application-目录整理2026-10-21)。
