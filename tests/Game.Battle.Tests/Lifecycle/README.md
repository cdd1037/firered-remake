# 战斗生命周期测试

本目录属于维护中的Game.Battle.Tests，通过标准dotnet test运行。覆盖真实公共回合、结算、替补、奖励、训练家与相关生命周期边界；具体范围以当前用例断言为准。

历史独立runner、退休结果JSON及完整旧目录不是运行前置。测试夹具只保留当前实际使用的数值向量，不为了复原旧报告重新生成证明文件。

受控领域状态不代表玩家自然走到该位置，也不证明Godot输入、渲染或真实音频。应用与原生冒烟分别承担这些边界，见[测试说明](../../README.md)。

普通 Tackle 与无 PP Struggle 的两个固定回合用例现直接声明 HP、PP、RNG 请求顺序和终态规则，并将不应变化的队伍字段与入场值逐项结构比较；不再依赖序列化队伍哈希或外置快照。迁移时先验证旧快照断言，再将其对应的规则结果保留为可阅读的用例定义。历史快照没有维护中的独立生成入口，不将当前产品输出冒充新原作 oracle。
