## Coverage

- Sprite fixture: 800 cases / 24,126 rows (OrbitFast 320 / 11,420; OrbitScatter 160 / 2,466; SprayWaterDroplet 320 / 10,240).
- Task fixture: 205 cases / 3,443 rows (CycleMagicalLeafPal 5 / 383; MoveSkyUppercutBg 180 / 2,620; StretchTargetUp 20 / 440).
- All 20 ordered slot pairs across singles/doubles for sprite, Sky, and Stretch. Geometry includes nonzero picture Y offset, opponent elevation, and distinct priorities.
- OrbitFast uses eight canonical angular phases, 63/191/255 boundaries, durations 0/-1/1/2/18/40, signed radius wrapping, and stop on the transition that returns before checking arg7. Scatter uses all eight 32-step phases.
- Spray uses seeds 0, 1, 0x12345678, 0xFFFFFFFF; both directions and attacker/target origins. Every case consumes exactly two source Random draws at creation and none later.
- Palette cases cover different palette slots, more than two full seven-color cycles, a negative delay counter, and init/early/later arg7 stops. Sky covers delays -32768/-1/0/1/2/20/32767, unsigned background wrap, and init/early/later stops. Stretch completes the exact ten-plus-ten-frame affine program and terminal restore.

## Schema

Each fixture contains kinds, configs, configColumns, sourceSha256, sourceSpans, geometry, conventions, and cases. Case key: kind:mode:actor:target:config. Mode 0 is singles and mode 1 is doubles.

Each case row contains:
- state: values under columns; includes tick and post-task state.
- sprites: arrays under spriteColumns, captured after AnimateSprites and before ordinary task dispatch.
- afterTaskSprites: same columns, Stretch-only post-task target state (including final affine reset).
- palettes: arrays under paletteColumns, captured after task dispatch. No embedded tick; use the row state tick.

Tick -1 follows synchronous CreateSpriteAndAnimate or task initialization. Tick 0 includes the ordinary scheduler pass on that same conceptual tick. Task data13/data14 are omitted because they hold host pointer handles. Matrix counts exclude the fixed battler allocations. Source BG3 globals are u16; task data are s16. Palette initial values use `(index * 73 + 31) & 32767`.

## Host adapters and validation

The exact observed functions/programs listed below are extracted verbatim and checked for verbatim inclusion in the generated C. The source files are SHA256 guarded before extraction. Host adapters provide fixed battler geometry/visibility/palette-slot mapping, zero loaded-sheet tile starts, task/pointer bookkeeping, BIOS ObjAffineSet arithmetic, and unused platform hooks. The union has a 4-byte alignment member to reproduce the source ARM 8-byte affine-command ABI used by `index << 3`; callback and interpreter bodies are unchanged. All fields retain their source signed widths. Source Random and BlendPalette bodies are extracted; wrappers only count calls/writes. Dummy animation and affine END declarations are extracted from sprite.c.

Both outputs were regenerated byte-identically. The complete authored C harness passed AddressSanitizer and UndefinedBehaviorSanitizer; LeakSanitizer was disabled because sandbox ptrace prevents it. No heap allocation is authored. Assertions verify per-creation RNG draws, no palette writes outside the two selected slots, zero live callbacks and no extra matrix allocations on completion. Additional checks verified spray flips, full Stretch restore, and terminal BG3 reset.
