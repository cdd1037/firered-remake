# Baton Pass reference

Run explicitly from the repository root:

```sh
python tests/Reference/BatonPass/generate.py --root . --output tests/Game.Presentation.Tests/Fixtures/baton-pass-source-vectors.json
```

The destination must be absent. It is ignored generated evidence, never a tracked golden and never generated by ordinary tests. The default suite has 12 complete trajectories / 297 rows: all six single/double actor layouts, ordinary geometry, hidden logical/sprite combinations, source Y clamp/elevation and shifted actor position/offset. It uses physical sprite IDs 4/9/13/22 rather than canonical actor slot numbers. No expanded combinatorial mode is needed for this callback's fixed arithmetic and no-argument branches.

The generator extracts unchanged `AnimBatonPassPokeball`, native source visibility/sprite selection, `GetBattlerSpriteFinal_Y` and affine prepare/set/reset helpers. The harness supplies only explicit geometry and engine boundaries. Rotation is zero in every supported path, so its BIOS seam asserts that and writes exact diagonal matrices. Source frame 0 is the constructor callback; subsequent frames run one callback until destruction. The dummy tile frame has no motion/timing effect.

Every matrix write is retained. Case 1 falls into case 2, making two writes and two counter increments on each of its first three ticks. Case 2 reaches 1120/466 at tick 6, then immediately resets the now-hidden actor to identity. Only the ball rises after that, at -6 pixels per callback, until its picture Y plus y2 is strictly less than -32. Actor raw position and x2/y2 are unchanged.

The Presentation comparator checks all rows, final hidden/reset state, full-root composition and completed-pose replacement, cancellation at every tick, and fail-closed operands/recipe/actor/companion ownership. The source import checks verify script order, exact indexed tiles and Pokeball/Spotlight palette identity. Source scripts and upstream build tools are never executed.
